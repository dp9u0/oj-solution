## Description (English)

A binary search tree can be generated by traversing an array from left to right and inserting each element into the tree. Given a BST `root` with distinct node values, output all arrays that could possibly have generated this tree.

Example 1:
Input: root = [2,1,3]
Output: [[2,1,3],[2,3,1]]

Example 2:
Input: root = [4,1,null,null,3,2]
Output: [[4,1,3,2]]

Notes: the number of nodes is in [0, 1000]; 1 <= node value <= 10^6; the number of valid arrays is guaranteed not to exceed 5000.

## 思路

递归交织（weave），输出规模保证 ≤ 5000：

1. 根必须是数组第一个元素；之后左右子树的元素可以任意交错，只要各自保持相对顺序（这正是子树递归出的序列）。
2. `BSTSequences(node)` = 左子树序列集 × 右子树序列集，两两做 weave；空子树返回 `[[]]`（乘法单位元）。
3. `weave(a, b, prefix)`：每次从 a 或 b 的头部取一个追加到 prefix，一边取空则剩余整段接上——递归枚举全部 C(|a|+|b|, |a|) 种交织。
