# 1062. 最长重复子串的长度

* algorithms
* Medium (58.38 %)

https://leetcode.cn/problems/longest-repeating-substring/description/

给你一个字符串 s ，找出并返回 最长重复子串 的长度。如果不存在重复子串，返回 0 。



示例 1：


输入： s = "abcd"
输出： 0
解释： 没有重复子串。


示例 2：


输入： s = "abbaba"
输出： 2
解释： 最长的重复子串为 "ab" 和 "ba"，每个出现 2 次。


示例 3：


输入： s = "aabcaabdaab"
输出： 3
解释： 最长的重复子串为 "aab"，出现 3 次。




提示：


1 <= s.length <= 2000
字符串 s 仅包含从 'a' 到 'z' 的小写英文字母。

## Hints
1. Generate all substrings in O(N^2) time with hashing.
2. Choose those hashing of strings with the largest length.

**Testcase Example:** `"abcd"`
