# 1216. 验证回文串 III

* algorithms
* Hard (57.4 %)

https://leetcode.cn/problems/valid-palindrome-iii/description/

给出一个字符串 s 和一个整数 k ，若这个字符串是一个「k 回文 」，则返回 true 。

如果可以通过从字符串中删去最多 k 个字符将其转换为回文，那么这个字符串就是一个「 k 回文 」。



示例 1：


输入： s = "abcdeca", k = 2
输 出： true
解释： 删去字符 “b” 和 “e”。


示例 2:


输入： s = "abbababa", k = 1
输 出： true




提示：


1 <= s.length <= 1000
s 中只含有小写英文字母
1 <= k <= s.length

## Hints
1. Can you reduce this problem to a classic problem?
2. The problem is equivalent to finding any palindromic subsequence of length at least N-K where N is the length of the string.
3. Try to find the longest palindromic subsequence.
4. Use DP to do that.

**Testcase Example:** `"abcdeca"
