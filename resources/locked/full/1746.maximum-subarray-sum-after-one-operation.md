# 1746. 经过一次操作后的最大子数组和

* algorithms
* Medium (60.05 %)

https://leetcode.cn/problems/maximum-subarray-sum-after-one-operation/description/

你有一个整数数组  nums 。你只能将一个元素  nums[i] 替换为  nums[i] * nums[i] 。

返回替换后的最大子数组和。

 

示例 1：


输入： nums = [2,-1,-4,-3]
输出： 17
解释： 你可以把-4替换为16(-4*(-4))，使nums = [2,-1, 16 ,-3]. 现在，最大子数组和为 2 + -1 + 16 = 17.

示例 2：


输入： nums = [1,-1,1,1,-1,-1,1]
输出： 4
解释： 你可以把第一个-1替换为1，使 nums = [1, 1 ,1,1,-1,-1,1]. 现在，最大子数组和为 1 + 1 + 1 + 1 = 4.

 

提示：


1 5
-10 4   4

## Hints
1. Think about dynamic programming
2. Define an array dp[nums.length][2], where dp[i][0] is the max subarray sum including nums[i] and without squaring any element.
3. dp[i][1] is the max subarray sum including nums[i] and having only one element squared.

**Testcase Example:** `[2,-1,-4,-3]`
