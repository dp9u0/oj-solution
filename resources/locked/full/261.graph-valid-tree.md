# 261. 以图判树

* algorithms
* Medium (51.9 %)

https://leetcode.cn/problems/graph-valid-tree/description/

给定编号从 0 到 n - 1 的 n 个结点。给定一个整数 n 和一个 edges 列表，其中 edges[i] = [a i , b i ] 表示图中节点 a i 和 b i 之间存在一条无向边。

如果这些边能够形成一个合法有效的树结构，则返回 true ，否则返回 false 。



示例 1：




输入: n = 5 , edges = [[0,1],[0,2],[0,3],[1,4]]
输出: true

示例 2:




输入: n = 5, edges = [[0,1],[1,2],[2,3],[1,3],[1,4]]
输出: false



提示：


1 <= n <= 2000
0 <= edges.length <= 5000
edges[i].length == 2
0 <= a i , b i < n
a i != b i
不存在自循环或重复的边
