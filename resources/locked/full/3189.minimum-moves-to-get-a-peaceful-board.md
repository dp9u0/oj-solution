# 3189. 得到一个和平棋盘的最少步骤

* algorithms
* Medium (21.87 %)

https://leetcode.cn/problems/minimum-moves-to-get-a-peaceful-board/description/

给定一个长度为 n 的二维数组 rooks ，其中 rooks[i] = [x i , y i ] 表示 n x n 棋盘上一个车的位置。你的任务是每次在垂直或水平方向上移动 1 格 车（到一个相邻的格子）使得棋盘变得 和平 。

如果每行每列都 只有 一个车，那么这块棋盘就是和平的。

返回获得和平棋盘所需的 最少 步数。

注意 任何时刻 两个车都不能在同一个格子。



示例 1：


输入： rooks = [[0,0],[1,0],[1,1]]

输出： 3

输入： rooks = [[0,0],[0,1],[0,2],[0,3]]

输出： 6

提示：


1 <= n == rooks.length <= 500
0 <= x i , y i <= n - 1
输入保证没有两个车在相同的格子。

## Hints
1. Think of a greedy method.
2. First, distribute the rooks in individual rows.
3. You can do this by sorting all rooks by their rows. Then assign the first one to the first row, the second one to the second row, and so on.
4. After you've distributed rooks across all rows, now do the same for columns.
5. Sort rooks by their columns and then assign the first one to the first column and so on.

**Testcase Example:** `[[0,0],[1,0],[1,1]]`
