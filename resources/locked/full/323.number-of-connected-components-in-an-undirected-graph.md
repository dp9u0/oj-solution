# 323. 无向图中连通分量的数目

* algorithms
* Medium (65.94 %)

https://leetcode.cn/problems/number-of-connected-components-in-an-undirected-graph/description/

你有一个包含 n 个节点，下标从 0 到 n - 1 的图。给定一个整数 n 和一个数组 edges ，其中 edges[i] = [a i , b i ] 表示图中 a i 和 b i 之间有一条边。

返回 图中已连接分量的数目 。



示例 1:




输入: n = 5 , edges = [[0, 1], [1, 2], [3, 4]]
输出: 2


示例 2:




输入: n = 5, edges = [[0,1], [1,2], [2,3], [3,4]]
输出: 1



提示：


1 <= n <= 2000
1 <= edges.length <= 5000
edges[i] = [a i , b i ]
0 <= a i <= b i < n
a i != b i
edges 中不会出现重复的边

**Testcase Example:** `5
[[0,1],[1,2],[3,4]]`
