# 3294. 将双链表转换为数组 II

* algorithms
* Medium (43.43 %)

https://leetcode.cn/problems/convert-doubly-linked-list-to-array-ii/description/

给定一个 双链表 的 任意 node ，其中的节点具有指向下一个节点的指针和上一个节点的指针。

返回一个 按顺序 包含链表中元素的整数数组。



示例 1：


输入： head = [1,2,3,4,5], node = 5

输出： [1,2,3,4,5]


示例 2：


输入： head = [4,5,6,7,8], node = 8

输出： [4,5,6,7,8]




提示：


给定列表中的节点数在范围 [1, 500] 内。
1 <= Node.val <= 1000
所有节点的 Node.val 互不相同。

## Hints
Use the pointer to the previous node to reach the head node.

**Testcase Example:** `[1,2,3,4,5]
5`
