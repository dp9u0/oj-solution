# 360. 有序转化数组

* algorithms
* Medium (63.13 %)

https://leetcode.cn/problems/sort-transformed-array/description/

给你一个已经 排好序 的整数数组 nums 和整数 a 、 b 、 c 。对于数组中的每一个元素 nums[i] ，计算函数值 f( x ) = ax 2 + bx + c ，请 按升序返回数组 。



示例 1：


输入: nums = [-4,-2,2,4], a = 1, b = 3, c = 5
输出: [3,9,15,33]


示例 2：


输入: nums = [-4,-2,2,4], a = -1, b = 3, c = 5
输出: [-23,-5,1,7]




提示：


1 <= nums.length <= 200
-100 <= nums[i], a, b, c <= 100
nums 按照 升序排列




进阶： 你可以在时间复杂度为 O(n) 的情况下解决这个问题吗？

## Hints
1. x^2 + x will form a parabola.
2. Parameter A in: A * x^2 + B * x + C dictates the shape of the parabola. 
Positive A means the parabola remains concave (high-low-high), but negative A inverts the parabola to be convex (low-high-low).
