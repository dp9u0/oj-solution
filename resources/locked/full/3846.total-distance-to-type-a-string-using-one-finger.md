给定一个只包含小写英文字母的字符串 s 。返回一个整数，表示使用仅一个手指输入字符串 s 的总距离。手指初始位置在字母键 'a' 上。

两个位于 (r1, c1) 和 (r2, c2) 的按键距离是 |r1 - r2| + |c1 - c2| 。



示例 1：


输入： s = "hello"

输出： 17

解释：


你的手指从 'a' 开始，位于 (1, 0) 。
移动到 'h' ，位于 (1, 5) 。距离是 |1 - 1| + |0 - 5| = 5 。
移动到 'e' ，位于 (0, 2) 。距离是 |1 - 0| + |5 - 2| = 4 。
移动到 'l' ，位于 (1, 8) 。距离是 |0 - 1| + |2 - 8| = 7 。
移动到 'l' ，位于 (1, 8) 。距离是 |1 - 1| + |8 - 8| = 0 。
移动到 'o' ，位于 (0, 8) 。距离是 |1 - 0| + |8 - 8| = 1 。
总距离是 5 + 4 + 7 + 0 + 1 = 17 。



示例 2：


输入： s = "a"

输出： 0

解释：


你的手指从 'a' 开始，位于 (1, 0) 。
移动到 'a' ，位于 (1, 0) 。距离是 |1 - 1| + |0 - 0| = 0 。
总距离为 0。





提示：


1 <= s.length <= 10 4
s 只包含小写英文字母。

## Hints
1. Map each character to its (row, col) position on the keyboard grid.
2. Start from the position of 'a' and process the string from left to right.
3. For each move, add the Manhattan distance abs(r1 - r2) + abs(c1 - c2) between consecutive keys.
4. Accumulate the total distance and return the sum.

**Testcase Example:** `"hello"`
