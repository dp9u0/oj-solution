# 3879. 二叉树中的最大不同路径和

* algorithms
* Medium (51.57 %)

https://leetcode.cn/problems/maximum-distinct-path-sum-in-a-binary-tree/description/

给定一棵 二叉树 的 root ，其中每个节点包含一个整数值。

树中的 有效 路径是指一系列 相连 的节点，使得：


路径可以在树中的 任意节点 开始和结束。
路径 不 需要经过根节点。
路径上的所有节点值都是 不同 的。


返回一个整数，表示所有有效路径中节点值的 最大 可能总和。



示例 1：




输入： root = [2,2,1]

输出： 3

解释：


路径 2 → 2 是无效的，因为值 2 不唯一。
最大和的有效路径是 2 → 1 ，其和 = 2 + 1 = 3 。



示例 2：




输入： root = [1,-2,5,null,null,3,5]

输出： 9

解释：


路径 3 → 5 → 5 是无效的，因为值 5 不唯一。
最大和的有效路径是 1 → 5 → 3 ，其和 = 1 + 5 + 3 = 9 。



示例 3：




输入： root = [4,6,6,null,null,null,9]

输出： 19

解释：


路径 6 → 4 → 6 → 9 是无效的，因为值 6 出现了多次。
最大和的有效路径是 4 → 6 → 9 ，其和 = 4 + 6 + 9 = 19 。





提示：


树中的节点数范围为 [1, 1000] 。
-1000 <= Node.val <= 1000​​​​​​​

## Hints
1. Try all possible starting nodes
2. For a given node, the possible outgoing edges are the left child, right child, and parent
3. During depth first search (DFS), only visit a node if its value has not already been seen
4. Take the maximum over all possible starting nodes

**Testcase Example:** `[2,2,1]`
