# 4028. 得到旋转回文字符串的最少操作次数 II

* algorithms
* Hard (91.77 %)

https://leetcode.cn/problems/minimum-operations-to-make-a-rotated-palindrome-ii/description/

给你一个由小写英文字母组成的字符串 s 。

你可以按任意顺序执行以下操作任意次（包括零次）：


递增 ：选择任意一个下标 i 并将 s[i] 替换为下一个小写英文字母。 'z' 之后的字母是 'a' 。
左旋 ：将字符串的第一个字符移动到末尾。



返回使 s 成为 回文串 所需的 最少 操作次数。



示例 1：


输入： s = "abc"

输出： 2

解释：
一种最优方案：


左旋字符串： "abc" -> "bca" 。
递增 'a' 为 'b' ： "bca" -> "bcb" 。
"bcb" 是一个回文串。因此，答案是 2 。



示例 2：


输入： s = "yb"

输出： 3

解释：


将第一个字符递增三次： "yb" -> "zb" -> "ab" -> "bb" 。
"bb" 是一个回文串。因此，答案是 3 。





提示：


2 <= s.length <= 5 * 10 4
s 仅由小写英文字母组成。

## Hints
1. As in Part 1, for a rotation by r positions the answer candidate is r plus the sum of the cyclic letter distances over all mirrored pairs. The challenge is computing this sum for every rotation efficiently.
2. The cyclic distance between two lowercase letters can be represented using 13 binary features. For each k from 0 to 12, mark a letter if it belongs to the 13 consecutive cyclic letters starting at k . The cyclic distance between two letters equals the number of these features on which they differ.
3. For one such feature, create a binary array a over the positions of s . If cnt is the number of ones, then for a reflection represented by c , the number of mirrored pairs with different feature values is cnt - conv[c] , where conv[c] = sum(a[i] * a[(c - i) mod n]) .
4. Compute these circular self-convolutions for all 13 features using FFT or NTT. For a left rotation by r , use c = (2 * r - 1) mod n , sum the 13 contributions, and minimize this palindrome cost plus r .

**Testcase Example:** `"abc"`
