# 4060. 统计偶好数

* algorithms
* Hard (92.31 %)

https://leetcode.cn/problems/count-evenly-good-integers/description/

给你两个整数 l 和 r 。

如果一个整数包含偶数个偶数数字，则称这个整数为 偶好数 。

返回闭区间 [l, r] 中偶好数的数量。



示例 1：


输入： l = 18, r = 22

输出： 3

解释：

区间 [18, 22] 中的偶好数为：


19，因为它包含 0 个偶数数字。
20，因为它包含 2 个偶数数字。
22，因为它包含 2 个偶数数字。


因此，答案为 3。


示例 2：


输入： l = 98, r = 101

输出： 2

解释：

区间 [98, 101] 中的偶好数为：


99，因为它包含 0 个偶数数字。
100，因为它包含 2 个偶数数字。


因此，答案为 2。


示例 3：


输入： l = 1, r = 10

输出： 5

解释：

区间 [1, 10] 中的偶好数为 1、3、5、7 和 9，因为它们都包含 0 个偶数数字。因此，答案为 5。




提示：


1 <= l <= r <= 10 15

## Hints
1. 1a (Pairing). Consider pairs (2k, 2k + 1) for positive integers k . Their decimal representations differ only in the last digit, so exactly one integer in each pair is evenly good.
2. 1b (Pairing). Count all complete pairs contained in [l, r] . Check any unpaired endpoint separately by counting its even digits. This takes O(log r) time.
3. 2a (Digit DP). Let F(x) count evenly good positive integers at most x . The answer is F(r) - F(l - 1) .
4. 2b (Digit DP). Track the digit position, whether the current prefix matches the bound, whether the number has started, and the parity of the number of even digits. Ignore leading zeros, but count zeros after the number has started. Accept completed positive numbers with even parity.
