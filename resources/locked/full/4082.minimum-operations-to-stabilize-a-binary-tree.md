# 4082. 稳定二叉树的最小操作次数

* algorithms
* Hard (80 %)

https://leetcode.cn/problems/minimum-operations-to-stabilize-a-binary-tree/description/

给你一棵 二叉树 的根节点 root 。每个节点都包含一个整数值，表示其当前状态。

如果对于每个节点 u ，都满足以下条件，则称这棵二叉树是 稳定的 ：


如果 u.left 存在，那么 |u.val - u.left.val| <= 1 。
如果 u.right 存在，那么 |u.val - u.right.val| <= 1 。


在一次操作中，你可以选择任意一个节点，将其值 增加 或 减少 1。

返回使整棵二叉树变为 稳定的 所需的 最少 操作次数。



示例 1：


输入： root = [5,8,3]

输出： 3

解释：




设 u 为值为 5 的根节点。通过 2 次操作，将左子节点的值从 8 减少到 6。此时 |u.val - u.left.val| = |5 - 6| = 1 。
通过 1 次操作，将右子节点的值从 3 增加到 4。此时 |u.val - u.right.val| = |5 - 4| = 1 。
因此，答案为 2 + 1 = 3 。



示例 2：


输入： root = [2,-1,-4]

输出： 5

解释：




设 u 为值为 2 的根节点。通过 4 次操作，将 u 的值从 2 减少到 −2。
通过 1 次操作，将右子节点的值从 −4 减少到 −3。此时 |u.val - u.right.val| = |−2 - (−3)| = 1 。
因此，答案为 4 + 1 = 5 。



示例 3：


输入： root = [0,-2,2,-3,null,1]

输出： 3

解释：




设 u 为值为 0 的根节点。通过 1 次操作，将左子节点的值从 −2 增加到 −1；再通过 1 次操作，将右子节点的值从 2 减少到 1。
此时 |u.val - u.left.val| = |0 - (−1)| = 1 ，且 |u.val - u.right.val| = |0 - 1| = 1 。
设 v 为 u 的左子节点，其当前值为 −1。通过 1 次操作，将 v 的左子节点的值从 −3 增加到 −2，使得 |v.val - v.left.val| = |−1 - (−2)| = 1 。
右子树已经满足条件，因为 |1 - 1| = 0 。
因此，答案为 1 + 1 + 1 = 3 。





提示：


树中的节点数在范围 [1, 5 * 10 4 ] 内。
-10 5 <= Node.val <= 10 5

## Hints
1. Try using tree DP. Let dp[u](x) represent the minimum number of operations needed to make the subtree rooted at u stable, assuming the final value of node u is x .
2. If node u has a child v , the final value of v must differ from x by at most 1. Therefore, the contribution of this child is min(dp[v](x - 1), dp[v](x), dp[v](x + 1)) . How can you combine the contributions of all children?
3. Computing the DP for every possible value of x would be too expensive. Observe that each DP function is convex and piecewise linear. Can you represent such a function efficiently using its breakpoints instead of storing all its values?
4. Consider how taking the minimum over [x - 1, x + 1] changes the breakpoints of a convex function. Use an efficient data structure to maintain these breakpoints and merge the functions of different subtrees.
