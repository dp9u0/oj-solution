# 4087. 最多交换 K 次的最大固定长度子数组的最大和

* algorithms
* Medium (57.83 %)

https://leetcode.cn/problems/maximum-subarray-sum-of-fixed-length-after-at-most-k-swaps/description/

给你一个整数数组 nums 和两个整数 length 和 k 。

你可以对 nums 执行 至多 k 次交换操作。

在一次交换操作中，你可以选择两个 不同 的下标 i 和 j ，交换 nums[i] 和 nums[j] 。

返回执行交换操作后，长度 恰好 为 length 的 子数组 的 最大可能元素和 。



示例 1：


输入： nums = [1,-1,0,2], length = 2, k = 1

输出： 3

解释：


交换下标 1 和 3 处的元素，得到 [1, 2, 0, -1] 。
子数组 [1, 2] 的长度为 2，元素和为 3。
由于 1 和 2 是数组中最大的两个元素，因此不存在长度为 2 且元素和更大的子数组。



示例 2：


输入： nums = [4,3,2,4], length = 3, k = 2

输出： 11

解释：


交换下标 2 和 3 处的元素，得到 [4, 3, 4, 2] 。
子数组 [4, 3, 4] 的长度为 3，元素和为 11。
这是数组中最大的三个元素之和，因此不可能得到更大的答案。只需要一次交换操作。



示例 3：


输入： nums = [-1,-2], length = 2, k = 0

输出： -3

解释：

不允许执行交换操作。唯一一个长度为 2 的子数组是 [-1, -2] ，其元素和为 -3。




提示：


1 <= nums.length <= 300
-10 9 <= nums[i] <= 10 9
1 <= length <= nums.length
0 <= k <= nums.length

## Hints
1. 1a (Greedy Exchanges) : Fix the position of the final subarray. Swapping two elements that are both inside it or both outside it does not change its sum.
2. 1b (Greedy Exchanges) : Sort the inside elements increasingly and the outside elements decreasingly. Pair the smallest inside elements with the largest outside elements, using at most min(k, length, nums.length - length) swaps and stopping when the gain is non-positive.
3. 1c (Greedy Exchanges) : Evaluate every subarray of the required length and take the largest resulting sum.
4. 2a (Sliding Window and Order Statistics) : Let b = min(k, length, nums.length - length) . Mark the indices of any length largest elements in the whole array. Their sum is an upper bound, attained whenever a window contains at least length - b marked indices.
5. 2b (Sliding Window and Order Statistics) : Otherwise, an optimum for that window can use exactly b outside elements. Its value is the sum of the largest length - b inside elements and the largest b outside elements.
6. 2c (Sliding Window and Order Statistics) : Maintain the inside and outside value counts and sums as the window slides. Coordinate compression and Fenwick trees support the required largest-element sum queries in logarithmic time.
