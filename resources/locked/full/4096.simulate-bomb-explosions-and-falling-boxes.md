# 4096. 模拟炸弹爆炸和掉落箱子

* algorithms
* Medium (81.63 %)

https://leetcode.cn/problems/simulate-bomb-explosions-and-falling-boxes/description/

给定一个大小为 m x n 的二维字符数组 grid ，其中每个单元格包含以下符号之一：


'#' ：一个箱子。
'-' ：一个空单元格。
'*' ：一颗炸弹。


每一秒，以下事件会 按顺序 发生：


爆炸： 如果一颗炸弹与至少一个箱子 上下左右相邻 （即共用一条边），则该炸弹会爆炸。爆炸的炸弹会摧毁其 周围 8 个相邻单元格 中的所有箱子，包括对角线方向相邻的箱子，并将这些单元格变为空单元格。所有爆炸 同时发生 ，并且均基于该秒开始时的网格状态。空单元格和炸弹保持不变。
重力： 爆炸结束后，所有 非静止 的箱子会 同时 向下移动恰好一行。如果一个箱子位于 最下一行 、紧挨着一颗炸弹的正上方，或者紧挨着另一个 静止 箱子的正上方，则该箱子是 静止 的。


炸弹永远不会移动或消失，同一颗炸弹可以多次爆炸。位于非静止箱子上方的箱子可以与其一起下落。

返回经过 10 100 秒后的最终 grid 。



示例 1：


输入： grid = [["#","#","#"],["-","-","*"],["-","-","-"]]

输出： [["-","-","-"],["-","-","*"],["#","-","-"]]

解释：

用 (r, c) 表示从上往下第 r 行、从左往右第 c 列的单元格。例如， (0, 0) 表示左上角的单元格。

第 1 秒：


由于位于 (1, 2) 的炸弹与位于 (0, 2) 的箱子上下左右相邻，因此位于 (0, 1) 和 (0, 2) 的箱子被摧毁，变为空单元格。
位于 (0, 0) 的箱子下落至 (1, 0) 。


第 2 秒：


位于 (1, 2) 的炸弹没有与任何箱子上下左右相邻，因此没有发生爆炸。
位于 (1, 0) 的箱子下落至 (2, 0) 。


此后不再发生任何变化。


示例 2：


输入： grid = [["-","*"],["#","-"]]

输出： [["-","*"],["#","-"]]

解释：
由于炸弹没有与任何箱子上下左右相邻，因此不会发生任何变化。

示例 3：


输入： grid = [["-","*","#"],["#","-","-"]]

输出： [["-","*","-"],["-","-","-"]]

解释：

第 1 秒：


位于 (0, 1) 的炸弹与位于 (0, 2) 的箱子上下左右相邻。因此，位于 (0, 2) 和 (1, 0) 的箱子被摧毁，变为空单元格。


此后不再发生任何变化。


示例 4：


输入： grid = [["#","*","-","#"],["-","-","*","-"]]

输出： [["-","*","-","-"],["-","-","*","-"]]

解释：

第 1 秒：


由于位于 (0, 1) 的炸弹与位于 (0, 0) 的箱子上下左右相邻，因此位于 (0, 0) 的箱子被摧毁，变为空单元格。另一颗位于 (1, 2) 的炸弹没有与任何箱子上下左右相邻。
位于 (0, 3) 的箱子下落至 (1, 3) 。


第 2 秒：


由于位于 (1, 2) 的炸弹与位于 (1, 3) 的箱子上下左右相邻，因此位于 (1, 3) 的箱子被摧毁，变为空单元格。另一颗位于 (0, 1) 的炸弹没有与任何箱子上下左右相邻。


此后不再发生任何变化。




提示：


1 <= m == grid.length <= 100
1 <= n == grid[i].length <= 100
grid[i][j] 为 '#' 、 '-' 或 '*' 。

## Hints
1. Determine which bombs explode using the grid at the beginning of each second. How can you mark boxes for destruction without affecting the other bombs?
2. After processing explosions, simulate gravity from the bottom row upward so that each non-static box falls by exactly one row.
3. Consider how far each box can fall before being destroyed or becoming static. Show that the grid stabilizes after at most n seconds, so simulating 10 100 seconds is unnecessary.

**Testcase Example:** `[["#","#","#"],["-","-","*"],["-","-","-"]]`
